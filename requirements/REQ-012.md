# REQ-012　设置页金属质感双圆角框

## 目标
依据用户提供的局部参考图，复现细薄、同心、带受光变化的 Ivory Jade 金属双圆角框，并将其统一应用到设置页的结构性外框。

## 为什么
当前外框主要依赖两套互相覆盖的样式，边线仍接近普通浅色描边，缺少参考图中由深金轮廓、象牙高光、浅金内线和暖色投影共同形成的精致立体感。

## 验收标准
- [x] AC-1 主题中提供单一、可复用的金属结构框样式，包含古金渐变外缘、象牙高光间隔、浅金内线与克制的暖色下投影。
- [x] AC-2 双线在直边与圆角处保持同心，视觉间距约 2–4 DIP；默认与最小窗口尺寸下无裁切、错位或异常滚动。
- [x] AC-3 金属框应用于导航塔、主设置面板、右侧概览、底部系统概览及窗口控制等结构性窗格；内部信息卡不被过度装饰。
- [x] AC-4 Release 测试全过，Windows win-x64 NativeAOT 发布无警告，并产出默认与最小窗口视觉证据。

## 关键决策
- 2026-07-20 直接依据用户参考图实现，不调用 huashu-design；金属感来自多层低对比边线与受光渐变，而非加粗金边。
- 2026-07-20 保留最左侧 Product Concept 平直侧栏，不给它增加圆角金属外框。
