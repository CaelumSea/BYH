# REQ-012　贴图磁力吸（magnetic snap for pinned notes，R52）

## 目标
R46 贴图窗口在拖动时自动吸附对齐：靠近**屏幕工作区边缘**（避开任务栏后的可视区）或其他**贴图窗口的可见边**时，在 ±8px 阈值内吸附对齐。按住 **Shift** 临时禁用磁力吸。

## 为什么
当前 R46 贴图支持任意位置拖动，但用户实际排贴图时几乎总是要对齐（左对齐、顶对齐、屏幕边缘对齐、贴图之间贴合）。手工对齐在高 DPI + 多屏 + NoActivate 窗口（窗口位置是物理像素，非 DIP）下误差很大，反复拖。磁力吸是钉贴图场景的标配（Snippy / Snipaste / PureRef 都有），实现成本仅 ~100 行（纯函数计算 + 拖动 hook）。

## 验收标准
- [ ] AC-1 拖动贴图时，若贴图左/右/上/下边距**屏幕工作区**（`SystemParametersInfo/SPI_GETWORKAREA` 取主屏 + `MonitorInfo` 取所有屏的工作区）相应边 ≤ 8px，松手后吸附贴齐（边重合）。
- [ ] AC-2 拖动贴图时，若贴图左/右/上/下边距**任意其他贴图窗口**的可见边 ≤ 8px，松手后吸附贴齐。
- [ ] AC-3 拖动过程中**实时**显示半透明吸附辅助线（金色 `#FFD9C28A`，2px 宽，alpha=0.6），提示用户即将吸附的边；松手时辅助线消失。
- [ ] AC-4 按住 **Shift** 拖动时，磁力吸完全禁用，吸附辅助线不显示，贴图位置完全跟随光标。
- [ ] AC-5 磁力吸算法作为纯函数单元测试 ≥ 8 个（边界命中：左/右/上/下 × 屏幕边/贴图边；阈值边界：7px 命中 / 9px 不命中；多贴图场景取最近；Shift 禁用直接返回原位置；负坐标 / 多屏负偏移正常）。
- [ ] AC-6 `dotnet build -c Debug` 0 警告 0 错误；`dotnet test` 全过；NativeAOT Release publish 0 trim/AOT 警告；exe 增量 ≤ +30KB（无新依赖）。
- [ ] AC-7 机器侧验证：贴图靠近屏幕右边 → 出现金色辅助线 → 松手后右边缘贴齐屏幕右边；按住 Shift 拖过同一位置 → 无辅助线 → 不吸附；同时开 2 张贴图，把第二张拖向第一张左边缘 → 辅助线 → 吸附贴合。

## 关键决策
- **接入点**：`PinnedScreenshotWindow.OnPointerMoved` 设置 `Position = ...` 时，先用 `MagneticSnapCalculator.ComputeSnap(target, screens, others, shift)` 算出吸附后位置；如果命中吸附，把辅助线信息暂存到字段；`OnPointerReleased` 时再算一次最终吸附（防止 release 时位置已超过阈值但拖动惯性大）。
- **辅助线 overlay**：不新开窗口，直接在 `PinnedScreenshotWindow` 自身上画（`Canvas` overlay + `Line` 控件，跟随窗口移动），命中吸附时 `Visibility=Visible`，否则 `Collapsed`。**不要**用另一个 top-level 窗口画线——多屏 + NoActivate 会出问题。
- **纯函数核心**：`MagneticSnapCalculator.ComputeSnap(windowRect, workAreas, otherRects, threshold, shiftHeld)` 返回 `(PixelPoint snappedPosition, SnapHint? hint)`。所有几何走**物理像素**（贴图窗口 `Position` 本身就是物理像素），不做 DIP 转换。
- **其他贴图列表来源**：`SelectionRuntime` 已维护 `_pinnedWindows`（`List<PinnedScreenshotWindow>`），暴露新属性 `IReadOnlyList<Rect> PinnedWindowPhysicalBounds`（每个元素的 `Bounds` 转 `PixelRect`），R52 调用方传入。
- **屏幕工作区来源**：`Screen.AllScreens` 已被 R40 用过；每个 `Screen.WorkingArea` 是 DIP，需要 × `RenderScaling` 转物理像素，或直接 P/Invoke `EnumDisplayMonitors` + `GetMonitorInfo` 拿物理 `rcWork`。优先用 P/Invoke（AOT 安全、无 DIP 歧义）。
- **Shift 检测**：用 P/Invoke `GetKeyState(VK_SHIFT=0x10) & 0x8000`，和 R47 的 Ctrl+Z 检测同模式（已在 `SelectionRuntime` 有引用）。
- **阈值**：常量 `SnapThreshold = 8.0`（物理像素）。
- **性能**：贴图数通常 < 5，O(贴图数 × 4 边) 每次拖动事件计算 < 1ms，不需要异步。
