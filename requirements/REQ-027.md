# REQ-027　BYH 皮肤自定义与运行时切换系统

## 目标
为 BYH 建立可即时预览、持久化并安全回退的皮肤系统：用户既能切换内置皮肤，也能在受约束的编辑器中调整颜色、材质、圆角、阴影、字体与装饰图，而不影响窗口布局和功能行为。

## 为什么
Ivory Jade 已证明 BYH 的视觉可以成为产品体验的一部分，但当前主题资源、组件样式和装饰资产仍耦合在一个近千行 AXAML 中，并有若干硬编码颜色与图片。继续复制整份 AXAML 会造成主题漂移、修复重复和 NativeAOT 风险。需要先建立稳定的主题边界，再开放自定义能力。

## 验收标准
- [ ] AC-1 至少提供 Ivory Jade 与一个视觉差异明显的内置皮肤；切换后所有已打开 BYH 窗口即时更新，无需重启。
- [ ] AC-2 当前皮肤与用户调整项写入 `%LOCALAPPDATA%\BYH\appearance.json`，重启后恢复；文件损坏、皮肤缺失或资源无效时自动回退 Ivory Jade。
- [ ] AC-3 皮肤只控制语义颜色、材质、形状、阴影、字体和受限装饰资产，不得改变快捷键、布局结构、命令绑定、后台服务或数据文件。
- [ ] AC-4 设置页提供皮肤列表、缩略预览、即时试用、应用、取消恢复及“恢复默认”操作；试用态不得提前覆盖持久配置。
- [ ] AC-5 自定义编辑器至少覆盖基础背景、表面、主色、强调色、文字、边框、圆角和阴影强度，并在保存前检查必需字段、颜色格式和基本文字对比度。
- [ ] AC-6 用户主题采用版本化 JSON 清单与受限图片资源，不执行外部代码、不加载用户 AXAML；非法路径、超限图片和未知 schema 版本被拒绝。
- [ ] AC-7 Debug 构建、核心测试和 win-x64 NativeAOT 发布通过；切换皮肤不改变 Ocean Eyes、Toolbar、Spotlight、Clipboard History 与 Launcher 的交互行为。
- [ ] AC-8 设置窗口恢复独立的系统标题栏，使用 Windows 原生最小化、最大化、关闭、拖动、双击最大化、Snap Layout 与高 DPI 行为；主题主体从标题栏下方开始。
- [ ] AC-9 右侧手机摘要卡的五个底部图标是可聚焦、可点击的真实按钮，并具有明确的悬停、按下、焦点与选中反馈。
- [ ] AC-10 右侧手机摘要卡在默认、最大化与全屏尺寸下仅比中央主内容窗格略矮，宽度随可用空间适度增长；中央窗格不独占横向余量。底部 System Overview 使用响应式高度并随全屏空间同步增高；上下两排大面板之间及窗口底边留出协调的宏观间距，整体比例协调且不裁切内容。
- [ ] AC-11 手机底部五个按钮只切换手机卡内部的独立摘要视图，不再切换中央设置页；手机视图具有独立选中态、键盘焦点与可验证的内容变化。
- [ ] AC-12 中央工作区恢复为单一、连续的大圆角主窗，直接承载 Dashboard 与各设置页；不保留冗余搜索条、接缝连接线、搜索浮层或第三层外框，并恢复与其他主题大面板一致的香槟金立体边框。
- [ ] AC-14 中央内容区新增 Dashboard 默认页，展示已启用模块、常用功能、当前 Provider/Model、服务状态和本地使用频率；无历史数据时提供真实空状态，不伪造统计。
- [ ] AC-15 移除设置页自绘标题栏、双箭头及窗口按钮自动隐藏模式，恢复最初稳定的独立系统标题栏；保留已经完成的最大化响应式列宽、手机卡比例与底部面板高度调整。
- [ ] AC-16 右上手机摘要卡使用 `Hi! {用户名}` 问候；默认采用 Windows 当前用户名，用户可在 General 页面编辑并保存覆盖值，保存后即时更新，重启后从 `%LOCALAPPDATA%\BYH\profile.json` 恢复；空白值恢复系统用户名。

## 关键决策
- 产品界面称“Skin / 皮肤”，代码与文件格式使用 `Theme`，避免和 Avalonia 控件模板概念混淆。
- 采用“固定组件样式 + 可替换语义令牌 + 受限资产”的三层模型，不允许皮肤任意重排界面。
- 内置主题编译进程序；用户主题解析为强类型 JSON 后生成运行时资源。禁止运行时加载外部 AXAML，因为项目启用 NativeAOT，而且外部 XAML 也扩大了代码注入与兼容风险。
- 首版建议先完成“内置切换 + 自定义编辑器 + 保存为本地皮肤”；主题包导入/导出作为下一批建立在同一 schema 上。
- 设置窗口使用独立的 Windows 系统标题栏，不再把标题栏并入皮肤主体，也不自绘或自动隐藏窗口控制按钮；窗口行为不属于皮肤。
- 手机卡是独立的信息微界面；底部五个按钮只切换手机内部内容，不再充当中央设置页的第二套导航。
- Dashboard 统计坚持本地优先，只展示真实可获得的数据；尚未采集的指标显示空状态，不使用装饰性假数字。
- 当前设置项数量较少，首版不提供设置搜索；左侧导航足以完成定位，中央区域优先保持单一、稳定、连续的主窗结构。
