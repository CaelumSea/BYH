# REQ-009　设置页框架比例与双层边框精修

## 目标
依据用户的红色标注图，精修设置页的大型框架、装饰背景和上下区域比例，让 Ivory Jade 的层次更精致、布局更协调。

## 为什么
当前导航塔的双层边框间距过大，装饰背景被内框遮挡；中央上下区域比例失衡，最左侧概念栏的圆角外框也偏离参考图的平直分栏结构。

## 验收标准
- [x] AC-1 BYH 导航塔的内外边框间距缩至约 4–6 个逻辑像素，并以相邻双金线、象牙高光和柔和暖阴影形成克制的立体层次。
- [x] AC-2 导航装饰背景移入内框并位于内容后方，保留原有重心在下的构图，不能只在边缘露出或影响文字可读性。
- [x] AC-3 中央上方设置工作区适当降低、下方 System Overview 增高；移除其标题与内容间的横向分割线，使底栏成为一体。
- [x] AC-4 最左侧 Product Concept 信息栏取消圆角外框，以较粗的古金色竖线与右侧区域分隔，同时保留内部内容分区。
- [x] AC-5 在默认窗口与 1240×680 最小逻辑尺寸（175% DPI）下无裁切、重叠或滚动异常，并通过完整测试与 Windows NativeAOT 发布。

## 关键决策
- 2026-07-20 导航背景保留原图重心在下的构图，只调整其所在层级：用户明确要求直接放入内框。
- 2026-07-20 仅最左侧概念栏取消圆角；BYH 导航塔继续保留双层圆角框架。
