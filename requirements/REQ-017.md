# REQ-017　设置页阴影层次与左栏柔化 v2

## 目标
以 Hotkey 卡片的柔和浮起阴影为基准，统一设置页宏观面板的立体语言，并修正左侧栏横纵线粗细失衡的问题。

## 为什么
第一版已经解决断边与重复框，但大面板的阴影仍比内部 Hotkey 卡片更弱，左右层次不统一；最左概念栏的纵向金线也明显重于横向分隔线，使左侧看起来生硬、偏平。

## 验收标准
- [x] AC-1 大面板参考 Hotkey 卡片建立一致的柔和浮起阴影，同时保持边框克制且无厚重描边。
- [x] AC-2 最左侧栏横线与纵线使用一致的细度和低对比颜色，不再出现纵线明显更粗的问题。
- [x] AC-3 导航塔和最左概念栏增加适度立体层次，默认与最小窗口下阴影连续且不裁切。
- [x] AC-4 Release 构建、测试、NativeAOT 发布及视觉截图验证通过。

## 关键决策
- 立体感来自近距离接触阴影、宽而淡的扩散阴影与顶部内高光，不通过加深描边实现。
- 左侧分隔线统一使用半透明暖金色 1 DIP；导航塔可浮起，但最左概念栏保持直角结构。
- 本轮只调整视觉层次，不改动设置功能内容。
