# REQ-006　设置页柔和边界、宝石裁切与侧栏比例修正

## 目标
依据用户标注的局部截图继续精修 Ivory Jade 设置页：消除宝石缩放边缘问题，让容器边界更柔和，提升右上欢迎卡构图，并均衡左侧三个说明板块。

## 为什么
当前多窗格结构已成立，但宝石图片把源图边缘缩进圆形容器，窗格外框与阴影视觉权重偏高，右上人物区仍像两个独立模块，左侧三个说明板块高度节奏不够均衡，距离参考图的柔和与精致感仍有明显差距。

## 验收标准
- [x] AC-1 左侧导航头像、主标题主题徽记和左下徽记中的宝石不再出现源图边缘/黑边，缩放与裁切一致。
- [x] AC-2 设置页大窗格、卡片和分隔线改为更浅的瓷器色与低对比阴影，边界仍可辨识但不抢内容。
- [x] AC-3 右上欢迎区采用参考图式单一人物主视觉：APP icon 更大、与欢迎文字自然重叠衔接，运行摘要层级更紧凑。
- [x] AC-4 左侧 PRODUCT CONCEPT、COLOR LANGUAGE、WORKFLOW 三个说明板块高度与内边距更均衡，底部品牌徽记保持独立。
- [x] AC-5 保留全部 x:Name、事件处理、四个导航分区与真实运行摘要；Release 构建、测试、NativeAOT 与 175% DPI 截图通过。

## 关键决策
- 2026-07-18 不重绘宝石素材，优先用放大裁切隐藏 JPG 源图边缘，保持现有品牌图一致性。
- 2026-07-18 右上栏不增加新数据，使用真实 APP icon 与现有运行摘要重新组织视觉层级。
