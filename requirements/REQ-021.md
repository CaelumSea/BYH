# REQ-021　设置页对称小手机与参考式左栏 v6

## 目标
让紧凑手机面板与主设置面板保持对称、平衡的关系，并将最左栏重构成参考图式的四段主题索引。

## 为什么
上一版把“缩小手机”处理为顶对齐，破坏了右侧上下留白的平衡；左栏也加入了过多 editorial 与 field notes 信息，导致模块拥挤，偏离参考图干净、像主题样张的秩序。

## 验收标准
- [x] AC-1 紧凑手机面板在右侧上方区域垂直居中，上下留白近似均衡，并与相邻主面板形成协调对称关系。
- [x] AC-2 手机内部头像、状态摘要、任务列表与底部导航完整显示，默认与最小窗口均无裁切重叠。
- [x] AC-3 最左栏采用 Theme Concept、Color Palette、Typography、Icon Style 四段结构，分隔清晰、留白充足、无拥挤卡片。
- [x] AC-4 Color Palette 展示 Primary `#E8C89A`、Secondary `#D5A86A`、Accent `#8FAE5A`、Deep Brown `#6B4B2A`、Cream `#FFF7EE`、Ivory `#F6F1E6`、Border `#EAD8B8` 七个色样。
- [x] AC-5 不改变设置功能与绑定行为，Release 构建、测试和 Windows NativeAOT 发布通过，并完成五个页签截图验收。

## 关键决策
- 手机仅调整外部垂直对齐，不重新扩大内容，以保留“小手机”比例。
- 左栏直接学习参考图的四段式主题样张，不继续扩展杂志化叙事模块。
- 浅色色样保留细描边，深色色样不使用重阴影，保证色板清楚但轻盈。
