# REQ-003　重构设置页信息架构与默认窗口尺寸

## 目标
把 BYH 设置页从拥挤的单列长页面重构为宽屏分区界面，并高保真呈现用户参考图中的 Ivory Jade 奶油珠光质感。

## 为什么
旧版默认 560×640，九个区块连续堆叠，查找和编辑成本高；第一轮重构虽然改善了信息架构，但只借用了参考图的布局，缺少奶油光泽、细金装饰、珠光纹理和玉石焦点，因此视觉距离仍明显过大。

## 验收标准
- [x] AC-1 设置窗口默认尺寸明显增大，最小尺寸下仍可操作
- [x] AC-2 设置项按常规、翻译服务、自定义功能、视觉识别四个分区导航
- [x] AC-3 Provider 与 OCR 表单不发生横向挤压或高 DPI 重叠
- [x] AC-4 底部版本与退出操作固定可见，现有设置功能与事件保持可用
- [x] AC-5 设置页在保留可用性的同时，高保真体现参考图的奶油光泽、细金线、珠光纹理、玉石徽记与精致导航质感

## 关键决策
- 2026-07-18 保留第一轮“固定侧栏 + 单分区内容 + 固定底栏”的可用性结构，但重做视觉表面，不以普通企业设置页为目标。
- 2026-07-18 参考图作为视觉北极星；不引入人物角色，改用 BYH 专属玉石、珍珠和古金花丝装饰资产。

## 变更记录
- 2026-07-18 用户指出第一轮与参考图差距明显。新增 AC-5，将视觉高保真从隐含期待升级为硬验收标准。
