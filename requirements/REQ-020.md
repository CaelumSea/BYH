# REQ-020　设置页小手机比例与杂志式概念栏 v5

## 目标
让右上概览真正像一台独立的小手机，并把最左概念栏升级成有刊头、期号和编辑层次的杂志页。

## 为什么
当前右上概览仍与主面板接近等高，作为“小手机”的独立比例不够明显；左栏虽然已有报纸分区，但内容仍像产品说明目录，缺少杂志排版的标题张力、期刊元信息和编辑节奏。

## 验收标准
- [x] AC-1 右上概览面板在默认窗口下明显短于主设置面板并顶端对齐，呈独立小手机比例。
- [x] AC-2 手机头图、Current setup 与底部 dock 的缩放和间距协调，默认窗口信息完整，最小窗口无重叠。
- [x] AC-3 最左直角栏改为英文杂志编辑排版，包含刊头/期号、主题标题、颜色索引与编号工作流，保持背景图和直角结构。
- [x] AC-4 不改设置行为；Release 构建、334 项测试、Windows NativeAOT 与六张以上截图验证通过。

## 关键决策
- 手机仍位于右上原网格，但使用顶对齐和最大高度，不改变右下 Window controls 的功能位置。
- 杂志感通过刊头、folio、大小字级对比、编号和细线建立，不增加厚重装饰框。
