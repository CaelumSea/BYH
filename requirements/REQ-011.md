# REQ-011　数字序号标注（Ocean Eyes numbered badges，R47）

## 目标
在 Ocean Eyes 框选确认后，新增 **A**（Annotate）键进入数字标注模式：鼠标每点一次，在点击位置烧上一个圆形数字 badge（1, 2, 3, ...，颜色与 Ivory Jade gold accent 一致），数字自增；Ctrl+Z 撤销最近一个 badge；再次 A 或 Esc 退出标注模式；标注随截图一起保存（Enter 保存时 badge 烧入 PNG）。

## 为什么
截图后经常需要标注重点序号 —— "看这里的 ① 问题、② 修复、③ 验证"。当前只能用外部工具（Snipaste / ShareX）画，工作流被打断。把数字 badge 做进 Ocean Eyes 工具栏的标注子模式，零切换成本。

## 验收标准
- [ ] AC-1 Ocean Eyes 框选确认后按 **A** 进入数字标注模式：工具栏状态槽显示"标注模式 · 点击放序号 · Ctrl+Z 撤销 · A/Esc 退出"；此时鼠标左键不再触发 R41 重画（被标注模式吞键吞点击）。
- [ ] AC-2 标注模式下，每次鼠标左键点击在点击位置放一个圆形 badge：直径 28 DIP，gold accent（#FFD9C28A）填充 + 1px 古金描边 + 居中数字（白色 Bold）；数字从 1 自增。
- [ ] AC-3 Ctrl+Z 撤销最近一个 badge；连续 Ctrl+Z 多次可逐个回退至空。
- [ ] AC-4 再次按 **A** 或按 **Esc** 退出标注模式，badge 仍保留在 overlay 上；Enter 保存截图时，当前所有 badge 烧入 PNG（与截图同分辨率，badge 半径按当前 DPI 缩放）；Esc 退出整个 Ocean Eyes 时不保存。
- [ ] AC-5 标注 layer 是 Avalonia Canvas，挂在 RegionSelectOverlay 上，仅 Ocean Eyes + 标注模式激活期间存在；无新增原生依赖；常驻内存增量 ≈ 0。
- [ ] AC-6 NativeAOT 发布 0 警告；Debug build 0 警告 0 错误；测试套件全过（含新增 ≥ 3 个 NumberedBadgeRenderer / NumberedAnnotationSession 纯函数测试）。

## 关键决策
- 2026-07-20 触发键定为 **A**（Annotate），vkCode 0x41 必须在 OCR-lazy gate **之前**插入分支（A 是 A-Z 范围首字母，gate 之后会被吞掉）。
- 2026-07-20 标注模式独占左键 —— 进入模式时 mouse hook 的 SwallowCheck（R41 已有的"右键吞键"机制）扩展到左键，避免点击放 badge 时误触发重画。
- 2026-07-20 数字 badge 渲染分两路：UI 层用 Avalonia `Ellipse + TextBlock` 实时显示；烧入 PNG 时用 Skia（已在依赖中）按相同几何重绘，保证像素一致。
- 2026-07-20 本批仅做数字 badge；矩形/椭圆/箭头/画笔在 R48 标注工具集 —— 但本批预先把 AnnotationCanvas + AnnotationSession + undo stack 抽象好，R48 直接加新 tool 即可。
