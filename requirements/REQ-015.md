# REQ-015　标注工具集（rectangle / ellipse / arrow / pen / highlight，R48）

## 目标
扩展 R47 数字标注模式，在 A 进入标注模式后，按 **1/2/3/4/5** 切换 5 种绘制工具，鼠标拖拽即画对应形状。每种形状可撤销，保存 PNG 时烧入。

## 为什么
R47 只能放数字序号 badge——这是"标注位置"的场景（编号 → 看图说话）。但截图标注还有"圈出区域"（矩形/椭圆）、"指向元素"（箭头）、"涂改/划重点"（画笔/高亮）等场景。Snipy/Snipaste/ShareX 都有完整标注工具集，是 Ocean Eyes 把"截图 → 标注 → 分享"闭环做完的关键缺口。

## 验收标准
- [ ] AC-1 A 进入标注模式后，工具栏状态槽显示"标注模式 · [1]矩形 [2]椭圆 [3]箭头 [4]画笔 [5]高亮 · Ctrl+Z 撤销 · A/Esc 退出"。默认工具是 1（矩形）。
- [ ] AC-2 按 **1** 矩形工具：左键拖拽画矩形描边（金色 `#FFD9C28A`，2px）；松手完成。按住 **Shift** 拖拽约束为正方形。
- [ ] AC-3 按 **2** 椭圆工具：左键拖拽画椭圆描边（金色，2px）；松手完成。按住 Shift 约束为正圆。
- [ ] AC-4 按 **3** 箭头工具：左键按下到松开画一条带箭头的线段（金色，2px 线 + 12px 箭头头部）。
- [ ] AC-5 按 **4** 画笔工具：左键按下开始记录路径，移动时把每个点加入路径（金色，2px 圆头线段连接相邻点），松手结束路径。
- [ ] AC-6 按 **5** 高亮工具：同画笔但用半透明黄色 `#80FFEB3B`（alpha=0.5）+ 8px 宽。
- [ ] AC-7 **Ctrl+Z** 撤销最近一次绘制（数字 badge / 矩形 / 椭圆 / 箭头 / 画笔 / 高亮都进同一 undo stack）。**A** 或 **Esc** 退出标注模式（标注保留）。
- [ ] AC-8 Enter 保存 PNG 时，所有可见的标注（数字 badge + 5 种 shape）烧入 PNG。烧入走**手写 BGRA 像素操作**（不用 SkiaSharp），矩形/椭圆描边、线段、路径都自实现。允许 1px 锯齿（不抗锯齿），但形状几何正确、颜色正确、位置正确。
- [ ] AC-9 单元测试 ≥ 12 个：5 种工具的 hit-test/draw 纯函数 + shape record 相等性 + AnnotationSession undo stack 混合 badge 和 shape + 烧入 PNG 纯函数（给定 BGRA + shape list → 检查关键像素颜色）。
- [ ] AC-10 `dotnet build -c Debug` 0 警告 0 错误；`dotnet test` 全过；NativeAOT Release publish 0 trim/AOT 警告；exe 增量 ≤ +80KB（无新依赖，避开 SkiaSharp）。

## 关键决策
- **共用 undo stack**：把 `NumberedAnnotationSession` 升级为 `AnnotationSession`（或新增 `ShapeAnnotationSession`，二者都实现 `IAnnotationItem`）。`IAnnotationItem` 是 polymorphic record（`NumberedBadgeAnnotation` / `RectangleAnnotation` / `EllipseAnnotation` / `ArrowAnnotation` / `PenStrokeAnnotation` / `HighlightStrokeAnnotation`）。Undo 弹栈即可，不管类型。
- **AOT 安全**：record + sealed subclasses + pattern matching，**不引入** DI / reflection / dynamic type。`IAnnotationItem` 用接口而不是抽象类（接口在 NativeAOT 下更稳）。
- **工具切换**：在 `OnToolbarKeyPressed` 中，A 已经激活时，1-5（vkCode 0x31-0x35）切换 `_currentAnnotationTool` 枚举，并更新状态槽文本。
- **画布事件**：在 R47 已加的 mouse hook 路由基础上，左键 down/move/up 派发到当前工具的 handler。每个工具的拖拽几何通过纯函数计算（在 `AnnotationShapeGeometry` 静态类里），便于单元测试。
- **烧入 PNG**：扩展 R47 的 `BurnBadgesIntoPng`，改名 `BurnAnnotationsIntoPng`，遍历 `IAnnotationItem` 列表，分派到对应 draw 方法。新增的 draw 方法（DrawRectangleStrokeOnBgra / DrawEllipseStrokeOnBgra / DrawLineOnBgra / DrawPathOnBgra）走 Bresenham 算法 + alpha 混合。
- **避开 Skia**：和 R47 同样决策。SkiaSharp 会增 ~2MB AOT 体积。手写 BGRA draw 算法总量 ~200 行，可读、可测、AOT 安全。代价：不抗锯齿，但截图标注描边用 2-3px，锯齿可接受。
- **配色**：所有金色描边统一 `#FFD9C28A`（与 R44/R47 gold accent 一致），高亮黄 `#80FFEB3B`，箭头头部的箭头线段同金色。
- **不做的事**：本批次**不做** text 标注 / 模糊工具 / 马赛克 / 编号自动布局（这些留 backlog）。
