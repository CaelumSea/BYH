# REQ-018　设置页报纸栏与主题面板 v3

## 目标
继续贴近参考图：强化左侧报纸式栏目的纸张层次，统一增大右侧五个面板圆角并换成 Ivory Jade 暖象牙填色，同时让最右上概览成为明确的手机式界面。

## 为什么
v2 已统一阴影和线宽，但左栏分隔线略显过淡，五个宏观面板仍偏白且圆角不够舒展；最右上概览虽然纵向窄长，却缺少参考图手机面板的机身轮廓和底部导航语言。

## 验收标准
- [x] AC-1 左侧报纸栏分隔线适度增强但横纵保持同色同粗，并通过右侧柔影形成纸张层次。
- [x] AC-2 左栏之外五个宏观面板统一增大圆角，双层轮廓保持同心且阴影不裁切。
- [x] AC-3 五个面板内部使用 Ivory Jade 暖象牙主题填色，不再呈现纯白底。
- [x] AC-4 最右上概览面板形成独立手机界面语言，具有更大机身圆角和参考图式底部导航坞。
- [x] AC-5 Release 构建、334 项测试、NativeAOT 发布及默认与最小窗口截图验证通过。

## 关键决策
- 五个面板指导航塔、主设置面板、右上概览、底部 System Overview 与底部 Window controls；最左概念栏继续保持直角报纸栏。
- 面板填色采用暖象牙渐变而不是实心纯白，内容卡片继续维持更亮一级以形成层级。
- 手机底部导航坞仅表达设置概览的导航语义，不引入新的业务功能。
