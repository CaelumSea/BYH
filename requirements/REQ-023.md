# REQ-023　设置页艺术字与宝石背景迁移 v8

## 目标
强化右上手机的品牌识别，并把左栏大宝石装饰从底部迁移到 Theme Concept，形成更合理的视觉焦点。

## 为什么
手机头部的普通 BYH 粗体缺少艺术感；左栏的大宝石目前压在 Icon Style 后方，干扰图标样张，而 Theme Concept 使用的独立小圆形宝石与整体装饰语言不统一。

## 验收标准
- [x] AC-1 右上手机使用清晰可辨、与 Ivory Jade 风格协调的艺术字标替代普通 BYH 标题。
- [x] AC-2 左栏大宝石装饰不再出现在 Icon Style 后方，而是作为 Theme Concept 的背景焦点，并替代原有小圆形宝石。
- [x] AC-3 默认与最小窗口下艺术字、主题说明、色板和图标无重叠裁切，功能逻辑不变。
- [x] AC-4 Release 构建、334 项测试、NativeAOT 发布和截图验证通过。

## 关键决策
- 优先复用项目已有透明艺术字资源 `byh-wordmark.png`，避免引入不稳定的系统字体依赖。
- 大宝石继续复用 `ivory-jade-ornament.jpg`，通过顶部区域裁切和定位迁移，不新增图片资产。

- 2026-07-22：根据用户标注，新增手机艺术字和左栏宝石背景迁移。
