# REQ-004　设置页参考图同构多窗格布局

## 目标
把 BYH 设置窗口从“侧栏 + 单内容页”升级为与参考图结构同构的宽屏多窗格工作台，让概览、导航、编辑、摘要和快捷操作在同一视野内形成清晰层级。

## 为什么
当前版本已经具备 Ivory Jade 的色彩与材质，但空间组织仍明显简化，缺少参考图最有辨识度的多窗格构图。用户希望保留这套视觉语言，同时让设置页真正呈现参考图的宽屏仪表盘式排版，而不是只在颜色和圆角上接近。

## 验收标准
- [x] AC-1 设置窗口默认采用接近参考图的宽屏四列两行结构：左侧品牌概览、独立导航、中央主设置、右侧摘要，以及下方快捷入口和诊断窗格
- [x] AC-2 常规、翻译服务、自定义功能、视觉识别四个分区仍可切换，所有现有 x:Name、事件和设置功能保持可用
- [x] AC-3 右侧配置摘要展示真实的当前 Provider、快捷键与 OCR 状态，不使用虚构统计数据
- [x] AC-4 在 175% DPI 与最小窗口尺寸下无关键控件重叠或不可达，并通过自动测试、NativeAOT 发布与截图验收

## 关键决策
- 2026-07-18 采用参考图的空间骨架而不是复制其虚构 Dashboard 内容：所有窗格承载 BYH 的真实设置、状态和入口。
- 2026-07-18 保留四分区导航与现有控件绑定，主设置区内部滚动；外围概览、摘要和底部工具窗格持续可见。
- 2026-07-18 Huashu Design 只作为层级、留白和反填充检查清单，不启动重型三方案原型流程。
