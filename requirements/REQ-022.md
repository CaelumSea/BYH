# REQ-022　设置页左栏节奏与手机比例 v7

## 目标
让最左主题样张的四段高度更均衡，同时把右侧手机恢复为只比相邻主设置面板稍矮的参考图比例。

## 为什么
v6 的方向正确，但左栏上半部分仍占用过多高度，使左下 Typography 与 Icon Style 显得紧凑；手机面板则被压缩过多，与参考图“仅略矮”的比例不符。

## 验收标准
- [x] AC-1 左栏 Theme Concept 与 Color Palette 的多余纵向留白减少，Typography 与 Icon Style 获得更舒展的高度，四段整体分布均衡。
- [x] AC-2 右上手机面板在默认窗口仅比相邻主设置面板稍矮，仍保持上下近似对称留白。
- [x] AC-3 最小窗口下左栏文字、七色色样、字体样张、五个图标和手机内容无重叠或裁切。
- [x] AC-4 不改变功能逻辑，Release 构建、334 项测试、NativeAOT 发布和截图验证通过。

## 关键决策
- 左栏使用新的比例行高，把上两段让出的空间优先分配给 Icon Style，其次分配给 Typography。
- 手机不使用固定 Height，改为 Stretch + 对称垂直 Margin，使默认与最小窗口都能自适应。

## 变更记录
- 2026-07-22：根据用户对 v6 的实机评价，调整左栏段落节奏与手机相对高度。
