# REQ-002　Ivory Jade 主题系统与全界面落地

## 目标
把用户给定的 Ivory Jade 视觉语言落实为 BYH 的统一 Avalonia 主题系统，并覆盖所有用户可见窗口，在不改变既有功能和交互的前提下形成柔和、低调、精致且可持续扩展的产品外观。

## 为什么
BYH 已经达到可用 MVP，但当前界面仍由分散的深色硬编码组成，缺少稳定的品牌识别和可复用主题基础。Ivory Jade 用象牙白承担安静背景、用玉色表达真实操作、用焦糖棕承载文字、用古金作小面积细节，符合快捷便携工具低干扰但有质感的定位。

## 验收标准
- [x] AC-1 建立单一 Ivory Jade Avalonia 资源词典，完整覆盖用户给出的基础、品牌、文字、结构、反馈与交互色值；验证：检查主题资源文件的键和值并成功编译。
- [x] AC-2 设置、提示、模板编辑、翻译结果、工具条与 QuickTools 全部消费语义资源，旧深色硬编码不再残留；验证：静态扫描 Views 与逐窗视觉检查。
- [x] AC-3 按钮、输入框、卡片、导航/选中、禁用、焦点、成功、警告、错误和信息状态符合 Ivory Jade 组件规范，玉色只强调操作、金色仅作小面积高级细节；验证：样式资源审查与交互烟测。
- [x] AC-4 透明悬浮窗与 OCR 选区在不同桌面背景上仍清晰可辨，且不改变任何既有交互行为；验证：QuickTools/overlay 烟测与自动化测试。
- [x] AC-5 完整测试套件与 win-x64 NativeAOT 发布通过，最终可执行程序可打开设置页并触发 QuickTools；验证：dotnet test、dotnet publish 与实际运行。

## 关键决策
- 2026-07-18 采用单一语义资源词典并由各窗口通过 `DynamicResource` 消费：为后续换肤保留扩展点。
- 2026-07-18 透明悬浮窗使用 Ivory Jade 的带透明度派生色；OCR 选区使用独立的高可见功能语义色，避免品牌统一损害任意背景上的可识别性。
- 2026-07-18 不增加装饰图片或无意义图标：BYH 是低干扰桌面工具，主题靠材料、层级和状态建立识别度。
