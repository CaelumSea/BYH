# REQ-005　设置页 Ivory Jade 视觉精修与 APP icon 头像

## 目标
把已有多窗格设置页从“结构正确”提升为接近参考图精致度的 Ivory Jade 产品界面，并让真实 APP icon 成为右上角人物视觉焦点。

## 为什么
上一版已经完成四列两行布局，但顶部节奏、人物主视觉、卡片层级和装饰细节仍偏功能原型，未达到用户期望的柔和、精致与高级感。

## 验收标准
- [x] AC-1 右上角以用户提供的 APP icon 作为人物头像视觉焦点，并通过 Avalonia 资源 URI 在 NativeAOT 发布版正常显示。
- [x] AC-2 在不编造数据的前提下补齐参考图式顶部欢迎带、精细边框层级、轻量珍珠装饰和非均质卡片节奏。
- [x] AC-3 保留全部设置页 x:Name、事件处理和四个导航分区，功能及真实运行摘要不回退。
- [x] AC-4 默认尺寸与 1240x680 最小尺寸在 175% DPI 下无裁切，Release 测试与 NativeAOT 发布通过并留截图证据。
- [x] AC-5 可增加主题预览、操作流程、本机隐私状态等辅助模块以接近参考图的信息丰富度，但不得伪造统计或历史活动。

## 关键决策
- 2026-07-18 使用现有 `app-icon.png` 作为右上角欢迎卡人物主视觉，而不是继续使用玉石 emblem。
- 2026-07-18 用户允许增加辅助/临时模块；仅使用真实配置或静态说明，不制造假 Dashboard 数据。

## 变更记录
- 2026-07-18 增加 AC-5：允许用诚实的辅助模块补足参考图的信息密度与构图层级。
