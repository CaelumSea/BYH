# REQ-007　设置页导航上移与底部共享窗格

## 目标
将设置页导航栏收进上方工作区，并让下方共享窗格延伸到导航栏之下，以参考图的“上方多窗格、下方横向大窗格”关系强化整页上下节奏。

## 为什么
当前导航栏使用 `Grid.RowSpan="2"` 独立贯穿全高，导致下窗格只能缩在中央一列，与参考图不符。参考图中导航属于上排，下方大窗格横跨导航和主工作区；同时下窗格内部使用一个完整表面承载标题和分组内容。

## 验收标准
- [x] AC-1 保持 SettingsWindow 四列两行外骨架与中央独立滚动不变。
- [x] AC-2 导航栏只占上排，底部共享窗格横跨导航栏与中央设置区，并采用上标题下内容的参考图结构。
- [x] AC-3 运行模式、主题预览、配置与诊断内容及目录按钮功能全部保留。
- [x] AC-4 默认和最小窗口尺寸下无裁切或遮挡，并通过构建、测试和 NativeAOT 视觉验证。

## 关键决策
- 2026-07-20 保留 R30 四列两行外骨架和中央滚动逻辑，但同时调整导航与底部窗格的 Grid 归属：导航限制在上排，下方共享窗格跨导航与中央两列，避免影响其他 Agent 新增的 Ocean Eyes 功能和设置事件绑定。
- 2026-07-20 用户澄清“放上去”指导航栏不得跨越底排：删除 `Grid.RowSpan="2"`，底部窗格改为跨第 2、3 列；导航底部重复运行状态移入已有的下窗格表达。

## 变更记录
- 2026-07-20 `SettingsWindow.axaml` 删除导航的跨行布局，压缩导航纵向间距并移除重复运行状态卡；`SYSTEM OVERVIEW` 改为横跨第 2、3 列的统一上下窗格。
- 2026-07-20 Release 构建、232/232 测试、NativeAOT 发布和 175% DPI 默认/最小尺寸截图全部通过。
