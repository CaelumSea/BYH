# REQ-016　设置页宏观边框结构修正 v1

## 目标
依据用户提供的参考图，对设置页右侧宏观面板进行第一版结构性修正：统一同心金属框、分离阴影与内容裁剪，并消除滚动条和圆角填充造成的断边。

## 为什么
REQ-012 已建立多窗格与金属框基础，但最终截图仍存在主面板框线叠加、不同大面板材质不一致、默认滚动条伪装成断边，以及 System Overview 右上角出现斜切缺口等问题。这些问题必须先从结构上解决，再继续做内容密度和装饰细化。

## 验收标准
- [x] AC-1 主工作区、右侧概览、系统概览与窗口控制使用一致的同心宏观框结构，不再叠加独立大框。
- [x] AC-2 消除默认灰色滚动条造成的断边观感，并修复 System Overview 圆角缺口。
- [x] AC-3 默认与最小窗口下圆角连续、阴影不被裁切，五个设置页无内容回归。
- [x] AC-4 Release 构建、测试与 NativeAOT 发布通过，并产出默认窗口五页截图。

## 关键决策
- 宏观面板只能有一个边框与阴影所有者；内容裁剪放在独立的无阴影内层。
- 不调用 huashu-design，直接以用户参考图和最终 QA 截图为视觉依据。
- 第一版只修结构性边框、裁剪与滚动条，不在本轮重做各页功能内容。
