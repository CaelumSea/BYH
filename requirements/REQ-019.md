# REQ-019　参考色板亮化与导航均衡

## 目标
按参考图给定色板消除 v3 的暗米黄感，并让导航选中标识更宽、更居中、更均衡。

## 为什么
当前面板最深色阶偏灰黄，削弱了参考图的奶油高光与贵族感；导航选中项过窄，和导航塔宽度不成比例。

## 验收标准
- [x] AC-1 主画布与五个面板采用 Cream `#FFF7EE`、Ivory `#F6F1E6` 与更亮的近白高光，不再呈暗米黄色。
- [x] AC-2 装饰金使用 `#E8C89A` / `#D5A86A`，边框使用 `#EAD8B8`，玉色高光使用 `#8FAE5A`，深棕文字保持清晰。
- [x] AC-3 导航选中项明显加宽，在导航塔内水平居中，五个导航项的左右边界与图文节奏一致。
- [x] AC-4 Release 构建、334 项测试、Windows NativeAOT 发布及五页截图验证通过。

## 关键决策
- 保留 `#667731` 作为白字主要动作的深玉绿，以维持可读性；参考玉绿 `#8FAE5A` 用于高光、色样与焦点。
- 奶油白负责大面积底色，金色只承担金属边线和选中态，避免整页泛黄。
