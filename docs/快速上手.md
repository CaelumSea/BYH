# BYH 快速上手（内测）

> Windows 桌面效率工具：全局快捷键直达屏幕上选中或框选的内容——OCR 识别、即时翻译、剪贴板历史、启动器、提示词模板。
> 本文件只讲"解压到能用"，完整说明见 [README](https://github.com/CaelumSea/BYH)。

- 构建：**2026-10-30**（main `ff04e2d`，v0.1.0 + post-release 更新）
- 形态：NativeAOT 单文件，免安装、无需 .NET 运行时

---

## 1. 解压并启动

1. 解压这个 zip 到任意位置（如 `D:\Tools\BYH\`），**路径不要含中文或空格更稳妥**。
2. 双击 **`BYH.exe`**（同目录的 3 个 dll 必须一起保留，缺了界面起不来）。
3. 第一次启动会弹 **Windows SmartScreen**（"已保护你的电脑"），因为 exe 没有付费签名。点 **"更多信息" → "仍要运行"**。
4. 任务栏右下角出现 BYH 图标 = 启动成功。所有快捷键即刻可用。

> 不需要装 .NET。BYH 是 NativeAOT 单文件，自带运行时。
> 配置和数据都在 `%LOCALAPPDATA%\BYH\`（不在 exe 同目录）。删了这个目录 = 完全卸载。

---

## 2. 配置翻译 / OCR（必需，否则翻译用不了）

BYH 是 OpenAI 兼容客户端，需要一个 LLM provider。**推荐在设置 UI 里配**，不用改文件：

1. **右键托盘图标 → 打开设置**（或双击托盘图标）。
2. 左侧导航 → **Translation**。
3. 点 **"添加 Provider"** → 选预设（DeepSeek / SiliconFlow / Ollama 本地 / 自定义）。
4. 填：
   - **API Key**：去 provider 平台申请（[DeepSeek](https://platform.deepseek.com/) / [SiliconFlow](https://cloud.siliconflow.cn/) 都有免费额度）。Key 用 DPAPI 加密存到 `%LOCALAPPDATA%\BYH\secrets\`，不会出现在任何配置文件或日志里。
   - **模型**：预设会带默认模型，可改。
5. **保存** → 回到设置主页确认 provider 下拉能选中它。

**OCR（截图识别）**用哪个 provider 单独配：设置 → **Vision**，选一个支持多模态的 provider + 模型（如 SiliconFlow 的 `nex-agi/Nex-N2-Pro`，又快又准）。

### 命令行方式（备选，不想进 UI 时）

```cmd
:: 1. 启动一次 BYH（建好配置目录）
BYH.exe

:: 2. 关掉它，编辑配置（可选——也可以完全在 UI 里加）
notepad %LOCALAPPDATA%\BYH\providers.json

:: 3. 写 API key（DPAPI 加密，不回显）
BYH.exe --set-secret secret://provider/你的providerId 你的APIKey
```

附带的 `providers.example.json` 是当前默认模板，想手写可以从它复制。

## 3. 默认快捷键

| 功能 | 快捷键 | 说明 |
|---|---|---|
| **Ocean Eyes**（区域截图 OCR） | `Ctrl+Alt+Q` | 拖框选屏幕区域 → OCR。框选后可按 `F`/`J`/`Z` 等做翻译/识别/标注（见工具栏提示）。截图同时落盘到 `%USERPROFILE%\Pictures\Ocean Eyes\` |
| **Spotlight 启动器** | `Ctrl+Alt+Space` | 弹出搜索面板，启动配置的应用/网页。先去设置 → Launcher 添加条目。 |
| **剪贴板历史** | `Ctrl+Alt+V` | 弹出本地剪贴板历史（**文本 + 图片**），自动分类、可置顶（Pin ★）、可加标签、长按可多选批量删除。 |
| **选词工具栏** | 选中文字后自动浮出 | 选中任意文字，工具栏弹出，按提示词模板（翻译/总结/解释）调用 provider。 |
| **截图相册** | Ocean Eyes 里按 `G`，或托盘菜单「打开截图相册」 | 单击选中、**双击看大图**；选中后按 `Delete` 弹确认框，**再按一次 `Delete`** 即删除（按住 Delete 不会连删）。大图开着时删掉当前图会自动关掉大图。 |

所有快捷键都能在设置里改（支持 Ctrl/Alt/Shift/Win + A-Z/0-9/F1-F12/Space）。

## 5. 常见问题

**Q: SmartScreen 拦住了怎么办？**
点"更多信息" → "仍要运行"。这是没付费代码签名的正常现象，不是病毒。介意的话可以右键 exe → 属性 → 勾选"解除锁定"后再运行，能减少一次弹窗。

**Q: 翻译/OCR 没反应？**
99% 是 provider 没配好。检查：① 设置里 provider 是否选中 ② Vision 页是否单独配了 OCR provider ③ 看 `%LOCALAPPDATA%\BYH\logs\BYH.log` 的错误（key 已自动脱敏）。

**Q: 启动没反应 / 托盘没图标？**
可能上次没正常退出。任务管理器结束 `BYH.exe` 进程再启动。BYH 是单实例，同一时间只能跑一个。

**Q: 剪贴板里的旧图片怎么不见了？**
图片历史有独立上限：设置 → 剪贴板 → **最大图片条数**（默认 50，**填 0 = 不限**），超过上限时最老的非置顶图片会被删除，`.png/.dib` 一起删、不可恢复；文本条目被挤掉时会进归档，在搜索里还能看到（带「已归档」徽章），**图片不进归档**。要长期留着就右键 **Pin ★**。
另外：`Pictures\Ocean Eyes\` 里的截图是独立落盘的文件，不受任何上限影响。

**Q: 开机自启？**
设置 → 通用 → **开机自启**（写 `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run`，不需要管理员）。也可以在任务管理器 → 启动里关掉它，BYH 下次启动时会同步显示真实状态。

**Q: 怎么完全卸载？**
① 任务管理器结束 `BYH.exe` ② 删 exe 所在目录 ③ 删 `%LOCALAPPDATA%\BYH\` ④ 想连开机自启一起清掉，先在设置里关掉自启。四步都做完就干净了。
